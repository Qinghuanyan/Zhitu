# 当前界面与功能对接清单

> 更新时间：2026-05-16  
> 说明：下面按“用户看到的功能”描述当前状态，不再用内部类名或路由名做主标题。

## 一、已经接入到新旅行主界面的 2.0 细节页

### 1. 个人中心总览
- 顶部头像可直接打开个人中心全屏层
- 可展示用户昵称、副标题、三项统计信息
- 个人中心内支持“历史记录 / 收藏推荐”双 tab

### 2. 历史记录页签
- 可展示最近历史会话卡片
- 每张历史会话卡片可继续恢复到对应会话
- 可展示当前行程摘要卡片
- 当前行程卡片可直接查看行程或重新规划
- 可展示历史行程卡片
- 历史行程卡片可直接查看行程或切回该会话继续调整
- 仍保留“一键打开完整历史页”的入口

### 3. 收藏推荐页签
- 可展示当前可用的收藏/推荐卡片
- Android 优先展示真实消息收藏；没有时回退展示当前行程里的酒店/美食/活动推荐
- web-ui 先展示当前行程里的酒店/美食/活动推荐
- 收藏卡片可继续打开对应推荐或会话内容
- 收藏项支持界面内移除视觉状态

### 4. 行程导出与分享
- 行程页内的导出、分享按钮已接入宿主动作
- Android：
  - 导出会生成 Markdown 文件到本地缓存导出目录
  - 分享会调用系统分享面板
- web-ui：
  - 导出走现有 Markdown 下载
  - 分享优先走浏览器分享，不能分享时回退为 Markdown 下载

### 5. 推荐与细节入口
- 酒店、美食、活动卡片仍可继续打开对应推荐入口
- 收藏卡片里的推荐项也可继续跳到对应类别
- 当前行程、历史行程、历史会话三类卡片都已具备壳内入口动作

## 五、建议你接下来重点验收的地方

- 顶部头像打开个人中心是否正常
- 历史记录 tab 是否真显示历史会话与历史行程
- 收藏推荐 tab 是否真显示收藏/推荐卡片
- 行程导出 / 分享是否在 Android 与 web-ui 都有动作

- 原有推荐页、设置页、历史页、收藏页是否仍可进入
